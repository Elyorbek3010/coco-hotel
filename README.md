# Coco Hotel Website Redesign

Official web platform repository for the Coco Hotel website redesign.

- **Existing website:** https://coco-hotel.uz/

---

## Planned Technology Stack

### Frontend
- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (v4)
- **Routing:** react-router-dom
- **HTTP Client:** axios

### Backend
- **Language:** Python
- **Framework:** Django (LTS 5.2)
- **API Toolkit:** Django REST Framework

### Database
- **Engine:** PostgreSQL
- **Cloud Provider:** Neon

### Deployment & Infrastructure
- **Frontend Hosting:** Vercel
- **Backend Hosting:** Railway
- **Database Hosting:** Neon
- **Administration:** Django Admin

---

## Git & Branching Strategy

The repository follows a structured branch workflow:

- `main`: Production-ready release branch.
- `develop`: Primary integration and active development branch.
- `feature/*`: Dedicated branches for specific features and tasks (e.g. `feature/project-setup`).
